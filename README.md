## Description

Richfield Connect is an institution-focused academic social engagement platform.

The system allows students to:

- Register an academic profile
- View a live profile preview
- View their student profile
- Create academic posts
- Like and unlike posts
- Delete posts
- Persist information using browser localStorage

## Installation

Install Node.js 18 or later.

Open the project folder in Command Prompt or PowerShell.

Run:

npm install


Then start the development server:

npm run dev


Open the URL displayed by Vite.


## Production Build

Run:

npm run build


Then:

npm run preview


## Local Storage

The application stores user information using:

richfield_connect_user


Posts are stored using:

richfield_connect_posts
